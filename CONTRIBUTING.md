# Contributing to AurumUSD Whitelist

Thank you for your interest in joining the AurumUSD whitelist! We appreciate your participation in our Bitcoin-backed stablecoin protocol.

## Ways to Contribute

There are two ways to join the whitelist:

### Option 1: Open an Issue

1. Navigate to the [Issues](https://github.com/AurumUSD/aurumusd-whitelist/issues) tab
2. Click on "New Issue"
3. Provide the following information:
   - Your GitHub handle
   - Reason for joining (early access, governance rights, or protocol testing)
   - Any relevant experience or background
4. Submit the issue

### Option 2: Submit a Pull Request

1. Fork this repository
2. Clone your fork to your local machine
3. Edit the README.md file
4. Add your GitHub handle to the Whitelist section in alphabetical order
5. Use the format: `- @your-github-handle`
6. Commit your changes with a clear message
7. Push to your fork
8. Submit a pull request to this repository

## Guidelines

- **One entry per person** - Submit only one GitHub handle
- **Alphabetical order** - Keep the whitelist sorted alphabetically
- **Proper format** - Use the format: `- @your-github-handle`
- **Be respectful** - Follow our code of conduct and community guidelines
- **Valid GitHub account** - Ensure your GitHub account is active and legitimate

## Review Process

All submissions will be reviewed by the AurumUSD team. We aim to process:
- Issues within 24-48 hours
- Pull requests within 1-3 business days

## Questions?

If you have any questions about contributing, please open an issue with the label "question".
